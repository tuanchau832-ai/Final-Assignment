# Report release checklist

- [ ] Obtain the Task 3 rubric, website template, report skeleton, and agreed reverse brief. Check the page copy and coverage against them.
- [ ] Obtain teaching staff approval if submitting a Vercel deployment instead of Google Sites.
- [ ] Confirm the client, group details, local evidence, stakeholder input and all design claims.
- [ ] Complete the weighted matrix with sourced scores and weights totalling 100%. Label simulated inputs, prototype screenshots, measured results and proposed milestones in context.
- [ ] Verify costs, quantities, units, dates, payers, maintenance, replacement and end-of-life assumptions.
- [ ] Check APA references, figure captions and credits, permissions, evidence register, AI documentation, and actual teammate contributions.
- [ ] Check the final word count against the 4,000-word cap and template exclusions. Resolve draft prompts and review the draft and index settings before public release.
- [ ] Configure the verified HTTPS app domain, follow the [verification checklist](../../website/tests/checklist.md), and confirm the Vercel deployment root is `website`.
