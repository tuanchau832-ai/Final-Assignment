# HanoiWaterWatch

## HanoiWaterWatch Persistent Development Protocol

Before starting or resuming authorized redesign work, read the available documents in `docs/superpowers/plans/`:

- `AGENTS.md` for the planning workflow
- `DESIGN.md` for redesign requirements
- `TASKS.md` for the task list and status
- `PROGRESS.md` for the latest checkpoint
- `DECISIONS.md` for recorded decisions
- `RESUME_PROMPT.md` for resume instructions

If any planning file is missing, report the gap. Reconcile the latest checkpoint with the current repository before continuing the next unfinished task.

After each meaningful milestone and before pausing when possible, update `TASKS.md` and `PROGRESS.md` with task status, changed files, verification results, blockers and the next action. Record significant decisions in `DECISIONS.md` as they arise.

Begin or resume implementation only when the user requests it.
