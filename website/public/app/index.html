WaterWatch app prototype

Prototype P2 of Hanoi WaterWatch. Residents see a colour-coded map of drain outfalls and get alerts; the environment authority manages alerts and station health. Use the controls to run the test scenarios.

Data source

Six simulated stations, one reading every 2 seconds.
